## What Sprint-Layout Is

Sprint-Layout is a board-layout editor for designers who already know the circuit and need copper on an outline. Sprint-Layout component placement sets each footprint on the pads it needs, and Sprint-Layout copper traces route those nets across the PCB layout view. You work in Sprint-Layout when the question has moved from pin names to where the tracks and holes sit on the panel.

Sprint-Layout board outline fixes the edge, the mounting holes, and the keep-out margin before the copper fills in. When the PCB layout view is clean, the layers are ready for the fabrication shop that will build the board.
